# Supervised Learning

In Supervised Learning, we give the model the "answer key". We train it on `(input, output)` pairs so it can predict outputs for new inputs.

## 1. Regression

Predicting a continuous number.
*   **Example**: Predicting house prices.
*   **Algorithm**: Linear Regression.

## 2. Classification

Predicting a category.
*   **Example**: Is this email Spam or Not Spam?
*   **Algorithm**: Logistic Regression, Decision Trees, Support Vector Machines (SVM).
