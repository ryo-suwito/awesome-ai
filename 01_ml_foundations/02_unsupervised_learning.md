# Unsupervised Learning

Here, we don't have labels. The AI must look at the data and find structure on its own.

## 1. Clustering

Grouping similar data points together.
*   **K-Means**: Find K centers of clusters.
*   **DBSCAN**: Density-based clustering (good for weird shapes).

## 2. Dimensionality Reduction

Reducing the number of variables while keeping important information.
*   **PCA (Principal Component Analysis)**: Project data onto axes that maximize variance.
*   **t-SNE / UMAP**: Great for visualization.
